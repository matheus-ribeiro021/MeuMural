Meu Mural 📌

Organize grupos, tarefas e trabalho em equipe de forma simples e eficiente.

Sobre o Aplicativo

O Meu Mural é uma aplicação desenvolvida para facilitar o gerenciamento de grupos, tarefas e a comunicação entre usuários.

A plataforma foi criada para permitir que equipes organizem suas atividades de forma rápida e centralizada, oferecendo recursos como autenticação segura, criação de grupos, gerenciamento de tarefas e um mural colaborativo visual.

O projeto possui:

  • ✔ Backend desenvolvido em Java Spring Boot
  • ✔ Frontend feito em React Native
  • ✔ Autenticação por JWT
  • ✔ Banco relacional estruturado

Principais Funcionalidades

  • 🔐Cadastro e login com autenticação JWT
  • 👤Perfil básico do usuário
  • 👥Criação e gerenciamento de grupos
  • 📝Criação, edição e exclusão de tarefas
  • 🔔Notificações básicas
  • 🔍Pesquisa e filtros no mural
  • 📍Geolocalização (futuro)
